# 统计任务书（模板）

适用场景：让 Agent 数数或求和，比如有几行匹配、几行满足条件、某一列的合计或平均。每个数字都以核对器能重算的式子交回，你不用再相信它算得对不对。

## 给你看的（这部分不发给 Agent）

1. 填好 `<...>`。「规则」和「式子」两节一字不改。
2. 问题要写成一个式子就能回答的样子。「器具一共花了多少」就是 `sum(采购.csv, 金额, 分项=器具)`。式子回答不了的问题（「几个人同意」）要改成交出处。
3. 核对：

   ```
   agent-cite-check <回报.md> --root <目录>
   ```

   拍了快照就加上 `--before before.json --writable "out/**"`。
4. 不符的数字会并列显示声明值和重算值。用重算值。

通过不代表的事：式子是不是你想问的那个问题。`rows(采购.csv, 分项=器具)` 按写出来的样子核对；如果有器具被记在别的分项下，核对器不会知道。

## 发给 Agent 的任务书

```text
## 目标
根据下面的文件回答这些问题，每个答案是一个数。
1. <问题 1>
2. <问题 2>

## 只读这些文件
- <路径/台账.csv>
- <路径/记录.md>

## 产出
交回的内容放进工作目录下新建的 <out/统计.md>，分两部分。

1. 一张表，列固定为：

| 编号 | 问题 | 数值 | 式子 |
|---|---|---|---|

- 式子：得出这个数值的式子，用反引号括起，以「= 数值」结尾（见「式子」）。
- 没有合适的式子时，式子一格写「无」，数值一格改写出处：路径:行号「逐字摘录」。

2. 一节「文件」：新建的每个文件写 `[+] 路径`。

## 式子
- `lines(文件) = N`                      文本文件的行数
- `count(文件, "文字") = N`              「文字」出现的次数
- `count(文件, /正则/) = N`              正则匹配的次数
- `lines_with(文件, "文字") = N`         含「文字」的行数
- `files(通配) = N`                      匹配 *.md 这类通配的文件数
- `rows(文件.csv, 列=值) = N`            满足条件的行数
- `sum(文件.csv, 列) = N`                一列的合计；avg、min、max 写法相同
- `sum(文件.csv, 列, 别的列=值) = N`     满足条件的行的合计
- `distinct(文件.csv, 列) = N`           一列里有几种不同的值
条件可用 = != > < >= <= 和 ~（包含）；多个条件用 and 连接。

## 规则
- 数字写全：1234 或 1,234；小数照算出来的写，没要求就不四舍五入。
- 路径照任务书里的写法写。
- 脚本会重算每个式子，对不上的数字不用。

## 边界
- 不改读的文件，只新建 <out/统计.md>。
- 不解读数字。
```

## 示例回报

针对 `examples/templates/workspace/` 里的合成文件。`npm test` 会对它跑核对器。
